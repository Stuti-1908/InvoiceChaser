# InvoiceChaser website

Marketing site for InvoiceChaser: collections for UAE businesses on WhatsApp, email and phone, in Arabic and English.

Plain HTML, CSS and JavaScript. No build step.

## Run locally

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8000
```

## Deploy

Works on any static host. For GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Before going live

- Replace `[Add your number]` in the contact section.
- Mark only features that are live today as "Live" in the platform section and FAQ.
- Re-check the e-invoicing dates against the UAE Ministry of Finance / FTA.
- The demo uses fictional companies (Al Noor Trading, Gulf Star Contracting). Keep real client data out of the site.
