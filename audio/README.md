# Call recordings

Add two recordings here (MP3 or WebM; make WebM files with recorder.html in Microsoft Edge) to replace the browser voices on the website:

- `call-en.mp3` or `call-en.webm`: the English reminder call
- `call-ar.mp3` or `call-ar.webm`: the Arabic reminder call

If a file is missing, the site falls back to the browser's own voices. The scripts are in `index.html` (search for `const CALL`).
